# custom_igarage_mobile_usage — การใช้แอปลงเวลาช่าง (iGarage)

ติดตามว่าแต่ละสาขาใช้แอปมือถือลงเวลาช่างกี่ % และลงเวลาตรงกี่ % ดึงข้อมูลจากระบบ iGarage
(MySQL + log เว็บ) มาเก็บใน Odoo อัตโนมัติ — เมนู **iGarage ลงเวลาช่าง**

## เมนู

| เมนู | ดูอะไร |
|---|---|
| ภาพรวมรายสาขา | pivot รายสาขา: จำนวนจ๊อบ / ใช้แอป (%) / ลงเวลาตรง (%) |
| เทียบแอปกับ PC | pivot สาขา × ช่องทาง (แอปล้วน / ผสม / PC ล้วน) — เทียบลงเวลาตรงในสาขาเดียวกัน |
| แนวโน้มรายวัน | กราฟเส้น % จ๊อบที่ใช้แอปต่อวัน |
| รายช่าง | สรุปรายช่างรายเดือน แถวเหลือง = ยังไม่เคยถูกบันทึกผ่านแอป (กรอง "ยังไม่เคยใช้แอป") |
| ข้อมูลละเอียด | รายจ๊อบ / รายชิ้นงาน |
| ตั้งค่า | ดึงข้อมูลตอนนี้ / ประวัติการดึงข้อมูล / ไฟล์ log ที่ประมวลผลแล้ว (เฉพาะผู้ดูแล) |

## นิยาม

- **ใช้แอป (จ๊อบ)** = มีอย่างน้อย 1 ชิ้นในจ๊อบที่บันทึกผ่านแอป
- **ลงเวลาตรง** = กดเริ่มกับกดจบห่างกันเกิน 60 วินาที; แบบจ๊อบดูทั้งจ๊อบ (เริ่มชิ้นแรก → จบชิ้นสุดท้าย)
  ชิ้นที่กดพร้อมกันในจ๊อบเดียวกันถือว่าทำไปด้วยกัน — **ไม่ได้แปลว่าเวลาตรงกับความจริง**
- **ไม่มีข้อมูล log** = วันที่ log เว็บยังมาไม่ถึง (วันนี้) หรือก่อนเริ่มเก็บ log — ไม่นับในตัวหาร % ใช้แอป
- ไม่รวมสาขา AKT, AMU (ไม่ใช่งานอู่) — ปรับได้ที่ `igarage.exclude_branch_ids`

## ทำงานอย่างไร

| งาน | รอบ | ทำอะไร |
|---|---|---|
| `iGarage: ดึงการลงเวลาช่างจากฐานข้อมูล` | ทุก 15 นาที | ดึงชิ้นงานที่เคลื่อนไหวใน 2 วันล่าสุด (เอาประวัติทั้งชิ้น) จาก `job_item_logs` |
| `iGarage: ดึง log เว็บ (แยกแอป/PC)` | ทุก 1 ชม. | โหลดไฟล์ `/logs/*.tar.gz` ที่ยังไม่เคยทำ (ทีละไม่เกิน 4 ไฟล์) เก็บวินาทีที่แอปสั่งลงเวลา แล้วจัดช่องทางให้ชิ้นที่เคยรอ log |

แยกแอป/PC: แอปส่ง api_key ใน URL → map เป็นโปรไฟล์ผู้บันทึก → ชิ้นงานที่ผู้บันทึกคนเดียวกัน
กดเริ่มห่างจากวินาทีที่แอปสั่งไม่เกิน ±4 วินาที = มาจากแอป (ฐาน iGarage เองไม่ได้เก็บว่ามาจากช่องทางไหน)

server iGarage รวบ log เป็นไฟล์ตอน 00:10 และเก็บไว้ ~27 วัน → % ใช้แอปช้า 1 วัน และถ้าระบบนี้หยุด
นานเกิน 27 วัน ข้อมูลช่วงที่ log ถูกลบไปแล้วจะแยกช่องทางไม่ได้

## ตั้งค่า (System Parameters)

`igarage.db_host` `igarage.db_port` `igarage.db_name` `igarage.db_user` `igarage.db_password`
`igarage.ftp_host` `igarage.ftp_user` `igarage.ftp_password` — ไม่ตั้ง = cron ข้ามเงียบๆ

ปรับได้ (มีค่าเริ่มต้น): `igarage.since_date` (2026-10-01), `igarage.exclude_branch_ids` (32,33),
`igarage.ontime_seconds` (60), `igarage.match_window` (4), `igarage.recent_days` (2),
`igarage.log_files_per_run` (4)

ระบบเขียนเอง: `igarage.log_covered_from`, `igarage.log_complete_until`

ดึงใหม่ทั้งหมด (หนัก ใช้ใน odoo shell): `env['igarage.usage.sync'].action_full_resync()`

## สิทธิ์

- `iGarage / ดูรายงานการใช้แอปลงเวลา` — เห็นเมนูรายงาน
- `iGarage / ผู้ดูแล` — + เมนูตั้งค่า, สั่งดึงข้อมูล (admin ได้อัตโนมัติ)
