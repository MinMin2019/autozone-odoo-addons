# Autozone Stock Count Sheet (ใบตรวจนับสต็อก) — `custom_stock_count`

ระบบตรวจนับสต็อกประจำสาขา จบในจอเดียว ตามแบบฟอร์มกระดาษ
`other/Autozone-แบบฟอร์มตรวจนับสต๊อก-BHA.xlsx`

เมนู: **Inventory → Operations → ตรวจนับสต็อก → ใบตรวจนับสต็อก**

## ขั้นตอนใช้งาน

| ขั้น | สถานะ | ทำอะไร |
|---|---|---|
| 1 | ร่าง | เลือก **สาขา/คลัง** (ตำแหน่งเก็บเติมให้เอง) วันที่นับ รอบการนับ ผู้นับ → กด **ดึงรายการสินค้า** |
| 2 | ร่าง | กด **พิมพ์แบบฟอร์ม (PDF)** หรือ **Export Excel** ส่งให้สาขานับ (ค่าเริ่มต้น = ไม่โชว์ยอดคงเหลือ) |
| 3 | ร่าง → กำลังนับ | กด **เริ่มนับ (ล็อกรายการ)** — รายการสินค้าแก้ไม่ได้แล้ว ยอดระบบถูก snapshot ใหม่ |
| 4 | กำลังนับ | คีย์ **ยอดตรวจนับ** ในตาราง (Tab/Enter ไล่ลงได้) หรือกด **นำเข้ายอดนับจาก Excel** อัปโหลดไฟล์ที่ Export ไปแล้วกรอกคอลัมน์ F |
| 5 | กำลังนับ → นับแล้ว | กด **ยืนยันผลนับ** → เห็นสรุปขาด/เกิน/มูลค่าผลต่าง (มูลค่าเห็นเฉพาะ Inventory Manager) |
| 6 | นับแล้ว → ปรับปรุงแล้ว | Inventory Manager กด **ปรับปรุงสต็อก** → สร้าง Inventory Adjustment ลงวันที่ = วันนับ (ย้อนหลังได้) รายการปรับปรุงผูกกลับมาที่ใบนับ (smart button) |

* รายการที่ **ยังไม่นับ** (คอลัมน์ "นับแล้ว" ว่าง) จะไม่ถูกปรับปรุง — ระบบไม่ถือว่าเป็น 0
* **นับได้ 0**: พิมพ์ 0 ทับ 0.00 เดิม web client ไม่ส่ง write (ไม่มีการเปลี่ยนค่า) → ให้ติ๊กช่อง "นับแล้ว" ของแถวนั้นเอง
  หรือคีย์รายการที่มีของครบแล้วกดปุ่ม **ที่เหลือ = 0** (รายการที่ยังไม่ได้คีย์ทั้งหมด = นับได้ 0); คีย์ผิดกดปุ่มยางลบท้ายแถวกลับเป็น "ยังไม่นับ"
* **รับเข้า / จ่ายออก คีย์เองได้** (สถานะกำลังนับ/นับแล้ว) — Odoo เติมให้ตอนดึงรายการ/เริ่มนับ แต่ถ้ามีรายการที่ยังไม่ได้คีย์เข้า Odoo
  (เช่น ยอดเบิกจากโปรแกรมอู่ที่คีย์รวมเดือนละครั้ง) ให้แก้ตัวเลขในช่องนี้เอง ระบบติ๊ก "รับ/จ่าย คีย์เอง" ให้และนับจำนวนไว้ที่สรุปผล
* **รีเฟรชยอดระบบ**: ดึงยอด ณ วันตัดยอด/รับ/จ่าย/ต้นทุน ใหม่จาก Odoo **ทับค่าที่คีย์เองทั้งหมด** (มีกล่องเตือนก่อน + บันทึก chatter ว่าทับรายการไหน)
  ปุ่ม ยืนยันผลนับ / ปรับปรุงสต็อก **ไม่รีเฟรชอัตโนมัติ** แล้ว (ตั้งแต่ 1.2.0) เพื่อให้ค่าที่คีย์เองคงอยู่
* **เลขที่ใบนับ** `IC-ปี-เลข 4 หลัก` (sequence `az.stock.count`)

## แบบฟอร์ม

* **PDF**: A4 แนวนอน หัวตารางซ้ำทุกหน้า เลขหน้าที่ท้ายกระดาษ ลายเซ็น 4 ช่อง
* **Excel**: เลย์เอาต์เดียวกับไฟล์ต้นแบบ (คอลัมน์ A-H, หัวหมวด merge, Leelawadee UI, แนวนอน fit 1 หน้ากว้าง,
  พิมพ์หัวตารางซ้ำ) + คอลัมน์ I = product id ตัวเทา ใช้ตอนนำเข้า **ห้ามลบ**
* ติ๊ก **ใบตรวจนับไม่แสดงยอดตามบัญชี** (blind count, ค่าเริ่มต้น) = Quantity/Amount/ผลต่าง เว้นว่าง จนกว่าใบจะอยู่สถานะ "นับแล้ว" ขึ้นไป (ยอดตามบัญชีแสดงเฉพาะชีต/รายงานกระทบยอด) เอาติ๊กออกต่อใบได้ถ้าจำเป็น
  จนกว่าใบจะอยู่สถานะ "นับแล้ว" ขึ้นไป (พิมพ์ซ้ำตอนนั้นจะได้ใบผลต่างครบ)

## ตัวเลือกดึงรายการ

* ดึงสินค้า **เก็บสต็อก (is_storable)** ที่มี quant ใต้ตำแหน่งเก็บที่เลือก (รวมตำแหน่งลูก) และยอด ≠ 0
* **รวมสินค้าที่ยอดเป็น 0** = เอาสินค้าที่เคยมีในคลังแต่ตอนนี้ 0 มาด้วย
* **เฉพาะหมวดสินค้า** = กรองตามหมวด (รวมหมวดย่อย) ว่าง = ทุกหมวด
* เรียงตาม หมวด (complete_name) → รหัสสินค้า → ชื่อ เหมือนแบบฟอร์มกระดาษ

## สิทธิ์

| กลุ่ม | ทำได้ |
|---|---|
| Inventory / User | สร้าง แก้ คีย์ยอด พิมพ์ นำเข้า ยืนยันผลนับ |
| Inventory / Administrator | + ปรับปรุงสต็อก, ลบใบ, เห็นต้นทุน/มูลค่าผลต่าง |

ขอบเขตคลัง (record rule ตั้งตอนติดตั้งโดย `post_init_hook`): มี `custom_warehouse_scope` → ใช้
`allowed_warehouse_ids`; ไม่มี → ใช้ Default Warehouse ของผู้ใช้ (ไม่ตั้ง = เห็นทุกใบ)

## เทคนิค / gotchas

* ปรับปรุงผ่าน `stock.quant` โหมด `inventory_mode` → `_apply_inventory()` (ทางเดียวกับ Physical Inventory ของ Odoo)
  ตั้ง `accounting_date` = วันนับ ให้ JE ลงวันนั้น แล้วประทับ `date` ของ stock.move / move line /
  `create_date` ของ valuation layer ตามวันนับ (แบบเดียวกับ `custom_stock_backdate`)
* ผูก move กับใบนับผ่าน `stock.move.az_count_id` (ส่ง context `az_count_id` ให้ `_get_inventory_move_values`)
* สินค้ามีของหลาย location ลูกใต้ตำแหน่งที่นับ → error ให้แยกใบนับตาม location
* สินค้าติดตาม lot/serial ปรับจากใบนี้ไม่ได้ (Autozone ไม่ใช้)
* ยอดนับที่คีย์แล้ว: `write()` ของ line ตั้ง `counted=True` ให้เองเมื่อมี `qty_counted` ใน vals
* ตัวนำเข้า Excel ใช้ `openpyxl` (มากับ Odoo) หาหัวตารางจากแถวที่ A = "ลำดับ" จับคู่ product id → รหัส → ชื่อ
