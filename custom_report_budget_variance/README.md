# Report Budget Variance

ใช้กับรายงานบัญชี (P&L, BS ฯลฯ) ตอนกดปุ่ม **งบประมาณ** แล้วเลือกงบ

| ก่อน | หลัง |
|---|---|
| คอลัมน์ `%` = ยอดจริง ÷ งบ | คอลัมน์ **ผลต่าง** = ยอดจริง − งบ (เป็นจำนวนเงิน) |
| เลือก analytic (เช่น ATZ) จะมีคอลัมน์ Balance หัวว่าง = ยอดทั้งบริษัท และ % เทียบกับยอดทั้งบริษัท | ตัดคอลัมน์ทั้งบริษัทออก ผลต่างเทียบกับยอดของ analytic ที่เลือก |

- สีเขียว = ดีกว่างบ (รายได้เกินงบ / ค่าใช้จ่ายต่ำกว่างบ), สีแดง = แย่กว่างบ — ตาม `green_on_positive` ของบรรทัด
- เลือกหลายสาขา: ยอดจริง = ผลรวมคอลัมน์สาขา (ถ้าเลือกแต่โซน ใช้ผลรวมโซน)
- ไม่ได้เลือก analytic: ยอดจริง = คอลัมน์ Balance ปกติ

Hook: `_init_options_columns` (ปรับหัวคอลัมน์ก่อนสร้าง columns) และ `_set_budget_column_comparisons`
(เรียกทั้งตอนโหลดรายงานและตอนกางบรรทัดย่อย)
