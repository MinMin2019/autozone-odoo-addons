# Autozone Asset Tracking

เฟส 1a ของระบบติดตามทรัพย์สิน: **ผู้ถือครอง (Custodian) ผูกกับข้อมูลพนักงาน**

## สิ่งที่โมดูลทำ
- เพิ่มช่อง **Custodian** (`custodian_id` → `hr.employee`) บนฟอร์ม/ลิสต์สินทรัพย์
- **ซ่อนช่อง Repository** (`x_asset_repository` จาก `asset_module`) — ข้อมูลเดิมยังอยู่ใน DB ไม่ลบ
- ตัวกรอง: *No Custodian*, *Custodian Archived (Resigned)* (ของค้างกับคนลาออก) + Group by Custodian
- ลิสต์สินทรัพย์แสดงเพิ่ม: **รูป**, **Description** (`x_asset_description`), **Analytic Distribution** (v1.1.0); ซ่อนคอลัมน์ Class (Studio) เพราะซ้ำกับ Analytic (v1.2.0)
- Group by **Analytic** / **Analytic Plan** ในลิสต์ ผ่านช่องซ่อน `main_analytic_account_id` (stored) = analytic ที่ % สูงสุดใน Analytic Distribution (v1.3.0) — สินทรัพย์ที่แบ่งหลายสาขาจะอยู่กลุ่มของสาขาที่ % มากสุด
- ช่อง Custodian มี tracking ใน chatter → เห็นประวัติเปลี่ยนคนถือ
- ค้นหาผู้ถือครองด้วย **รหัสพนักงาน** ได้ (v1.6.0): ดรอปดาวน์ช่อง Custodian แสดง "[รหัส] ชื่อ" + พิมพ์รหัสค้นได้, ช่องค้นหาลิสต์ "Custodian (name or code)" — `registration_number` ติดกลุ่ม HR จึงค้นแบบ sudo คืนแค่ id/รหัส ใช้ได้กับ user ที่ไม่มีสิทธิ์ HR; มีผลเฉพาะช่อง Custodian (context `az_employee_code_search`) ไม่เปลี่ยนการค้นพนักงานที่อื่น
- **รูปเพิ่มเติมหลายรูป** (v1.7.0): แท็บ **Images** บนฟอร์มทรัพย์สิน เพิ่มได้ไม่จำกัด + คำอธิบายรูป + ลากเรียงลำดับ + เห็นผู้/วันที่อัปโหลด (โมเดล `az.asset.image`, image.mixin ย่อไม่เกิน 1920px) — รูปหลัก (`image_1920` ของ asset_module) ใช้เหมือนเดิม และรายงานตรวจเช็คยังแสดงเฉพาะรูปหลัก; สิทธิ์: Accountant ขึ้นไปเพิ่ม/ลบได้, Read-only ดูได้อย่างเดียว

## แอป Assets (v1.8.0)
แยกงานฝั่งตัวของออกจาก Accounting เป็นแอปของตัวเอง (ไอคอนบนหน้าแรก) — **Assets › Asset Register** (ลิสต์เดียวกับ Accounting › Assets) และ **Assets › Operations** (ตรวจนับ, ต่อไปคือใบส่งมอบ/โอนย้าย)
งานคิดค่าเสื่อม/เพิ่มรายการ/ตัดจำหน่ายยังทำที่ Accounting เหมือนเดิม; ตอนนี้ใช้สิทธิ์กลุ่มบัญชีเดิม (Read-only ขึ้นไป)

## ใบส่งมอบ / ส่งคืนทรัพย์สิน (v1.8.0)
ตามแบบฟอร์ม `other/Autozone-ใบส่งมอบทรัพย์สินให้หน่วยงาน-แนวนอน.docx` — โมเดล `az.asset.handover` (+ `az.asset.handover.line`)
- เมนู **Assets › Operations › Asset Handovers** หรือติ๊กทรัพย์สินในลิสต์ → Actions › **Create Handover** (เติมรายการ + ผู้ส่ง ถ้าทุกชิ้นมีผู้ถือคนเดียวกัน)
- **1 ใบ = ผู้ส่ง 1 คน → ผู้รับ 1 คน**; เลขที่ **AST + ปี 2 หลัก + เดือน + 4 หลัก** (AST26100001) ออกตั้งแต่สร้างใบ รีเซ็ตทุกเดือนตามเดือนของวันที่เอกสาร
- ประเภท **ส่งมอบ** / **ส่งคืน** — ส่งคืน: ผู้รับคืนเริ่มต้น = ผู้จัดการต้นสังกัดของผู้ส่ง (ไล่ขึ้นตามผังแผนก) และเป็นผู้ถือครองคนใหม่
- ผู้จัดการต้นสังกัด (อนุมัติ) เติมให้จากแผนกของผู้รับ ไล่ขึ้นตามผังจนเจอคนที่ไม่ใช่ผู้ส่ง/ผู้รับ (แก้ได้); ห้ามเป็นคนเดียวกับผู้ส่ง/ผู้รับ
- พิมพ์ PDF ไปเซ็นกระดาษ (Draft = ช่องผลตรวจว่างให้ติ๊กมือ) → ได้ใบเซ็นคืน แนบสแกนใน chatter → **Confirm**:
  - ผู้ถือครองทุกรายการ = ผู้รับ, Location = "New Location" (ถ้ากรอก)
  - ติ๊ก **Change Depreciation Analytic** + เลือกเอง (บัญชีเลือกทุกครั้ง ไม่เดาจากแผนก) → เปลี่ยน analytic ของทรัพย์สิน = รายการค่าเสื่อมที่ยัง Draft เปลี่ยนตาม ที่ Post แล้วไม่เปลี่ยน
  - รายการ **ไม่พบ** ไม่เปลี่ยนอะไร (บันทึกใน chatter ของทรัพย์สิน)
  - ยืนยันไม่ได้ถ้าผู้ถือครองปัจจุบันไม่ใช่ผู้ส่ง หรือทรัพย์สินปิด/ขายแล้ว
  - ยืนยันแล้วยกเลิก/ลบไม่ได้ — ส่งผิดให้ทำใบกลับ
- ประวัติ: ปุ่ม **Handovers** บนฟอร์มทรัพย์สิน (ผู้ถือเดิม/ใหม่, ที่ตั้งเดิม, สภาพ, วันที่)
- สิทธิ์: Accountant ขึ้นไปสร้าง/ยืนยัน, Read-only ดูได้; ชื่อพนักงานอ่านผ่าน hr.employee.public ใช้ได้กับ user ไม่มีสิทธิ์ HR

## รายงานตรวจเช็คทรัพย์สิน (v1.4.0)
- เมนู **Assets › Operations › Asset Check Report** (ย้ายจาก Accounting ใน v1.8.0) หรือติ๊กรายการในลิสต์สินทรัพย์ → Print › Asset Check Report
- เลือก **สาขา** (Main Analytic) และ/หรือ **ผู้รับผิดชอบ** ได้หลายค่า + ติ๊กรวม/ไม่รวมรายการที่ยังไม่ระบุผู้รับผิดชอบ
- PDF A4 แนวนอน แยก 1 ชุดต่อ **สาขา** (ขึ้นหน้าใหม่ทุกสาขา, ผู้ถือครองทุกคนรวมในตาราง) จัดกลุ่มตาม Asset Model เรียงตามเลขบัญชีสินทรัพย์ของหมวด (v1.5.1)
- คอลัมน์: รูป, รหัส (`x_studio_asset_code`), ชื่อ+Brand/Model/S/N, ผู้ถือครอง, Location (`x_studio_location`), Description, วันที่ได้มา, มูลค่าเดิม, ช่องติ๊ก สภาพดี/ชำรุด/ไม่พบ, หมายเหตุ
- แบ่งหน้าเอง (v1.5.2): แถวสูงคงที่, หมวดที่ต่อหน้าใหม่ขึ้น "(ต่อ)", หน้าสุดท้ายมีรายการอย่างน้อย 1 แถวคู่กับสรุป+ลายเซ็นเสมอ (ค่าความสูงอยู่ต้นไฟล์ wizard/asset_check_report_wizard.py)
- หัวเอกสารมีช่องวันที่ตรวจ; ท้ายชุด: สรุปผล + ลายเซ็น 3 ช่อง (ผู้ตรวจนับ / ผู้จัดการสาขา / ฝ่ายบัญชี)
- พิมพ์เฉพาะสถานะ Draft / Running / Paused

## การย้ายข้อมูลตอนติดตั้ง (post_init_hook)
เทียบชื่อใน Repository กับชื่อพนักงาน (รวมคนที่ archive) หลังตัดคำนำหน้า (นาย/นาง/นางสาว/น.ส./ว่าที่ ร.ต.) และช่องว่าง
ใส่ให้เฉพาะที่ตรงพนักงาน **คนเดียวแบบเป๊ะ** — ชื่อสะกดต่าง/หาไม่เจอปล่อยว่าง ให้บัญชีเลือกเองตามไฟล์รายชื่อ

## ยังไม่ทำ (รอเฟสถัดไป ดูดีไซน์ custom_asset_tracking)
Location เป็นทะเบียนต้นไม้ (แบบ SAP), วันที่/ผลตรวจนับล่าสุด, แท็บทรัพย์สินที่ถือบนพนักงาน, คำขอตัดจำหน่าย, สติกเกอร์ QR, ตรวจนับผ่านมือถือ (ตอนนี้มีแบบฟอร์มกระดาษข้างบน)
