# Autozone Product SKU (`custom_product_sku`)

รหัสสินค้า SKU 11 หลัก ระบบออกให้อัตโนมัติ แยกจาก Internal Reference (`default_code`) และ Barcode (EAN ผู้ผลิต)

```
SKU = รหัสหมวด 4 หลัก + รหัสแบรนด์ 3 หลัก + ลำดับ 4 หลัก
      1101           002             0042      → 11010020042
```

- **รหัสหมวด**: ช่อง "รหัสหมวด SKU" บนหมวดสินค้า (`product.category.az_sku_code`) — หมวดที่ว่างไว้ไม่ออก SKU (วัสดุตัดจ่ายทันที, บริการ, รอจัดหมวด)
- **รหัสแบรนด์**: ช่อง "รหัส" ของแบรนด์ (`az.product.brand.code` จาก `custom_product_classification`) ต้องเป็นตัวเลข 3 หลัก, ไม่มีแบรนด์ = `000`
- **ลำดับ**: นับแยกต่อ หมวด+แบรนด์ — สินค้าปกติ 0001–9000, **สินค้าดัมมี่** (ติ๊ก "สินค้าดัมมี่" = ไม่ระบุยี่ห้อ ซื้อตามสเป็คในบรรทัด PO) 9001–9999

## พฤติกรรม

| เหตุการณ์ | ผล |
|---|---|
| สร้างสินค้าในหมวดที่มีรหัส | ได้ SKU ทันทีตอนบันทึก |
| หมวดยังไม่มีรหัส / แบรนด์ยังไม่มีรหัส | ยังไม่ออก ฟอร์มขึ้นเหตุผลสีส้ม — พอใส่รหัสหมวด/แบรนด์ ระบบออกให้สินค้าที่รออยู่ทั้งหมด (เรียงตามรหัสเดิม) |
| ย้ายหมวด / เปลี่ยนแบรนด์ / ติ๊กดัมมี่ หลังได้ SKU แล้ว | **SKU ไม่เปลี่ยน** (ล็อก) |
| แก้ SKU เอง / import ทับ | ถูกปฏิเสธ |
| จัดหมวดผิดจริง | ผู้ดูแลรหัสสินค้ากดปุ่ม **ออกรหัส SKU ใหม่** (ใส่เหตุผล) → SKU เก่าเก็บในแท็บ "ประวัติ SKU", ถ้าติ๊ก "พิมพ์ฉลาก SKU แล้ว" ไว้จะเตือนให้เปลี่ยนฉลาก |
| สินค้าถูกเก็บถาวร/ลบ/ออกรหัสใหม่ | เลขเดิมไม่ถูกนำกลับมาใช้ (ตัวนับเดินหน้าอย่างเดียว + ตรวจกับประวัติ) |
| สินค้าบางตัวไม่ต้องมี SKU (เช่น ขนมในหมวดค่ารับรอง) | ติ๊ก **ไม่ออก SKU** ที่สินค้า — เอาติ๊กออกเมื่อไรได้ SKU ทันที (ติ๊กได้เฉพาะตัวที่ยังไม่มี SKU) |
| เจนไปแล้วแต่ไม่ต้องการ | ผู้ดูแลรหัสสินค้ากด **ยกเลิก SKU** (ใส่เหตุผล) → SKU ออก + ติ๊ก "ไม่ออก SKU" ให้, เลขเก็บในประวัติ ไม่นำกลับมาใช้ |
| คัดลอกสินค้า | ได้ SKU ใหม่ |
| บาร์โค้ดตรงกับ SKU ตัวไหน (หรือกลับกัน) | ถูกปฏิเสธ |

ค้นหาด้วย SKU ได้ทั้งช่องค้นหาสินค้า และช่องเลือกสินค้าในเอกสาร (PO / ใบโอน ฯลฯ) — พิมพ์หรือสแกน SKU ตรงตัวจะเจอสินค้านั้นก่อน
SKU **ไม่** แสดงหน้าชื่อสินค้าในเอกสาร (เอกสารยังใช้ Internal Reference ตามเดิม)

## สิทธิ์และเมนู
- หน้า **รหัสหมวด SKU** (คลังสินค้า › การตั้งค่า › จัดกลุ่มสินค้า): หมวดย่อยล่างสุดทั้งหมด + จำนวนสินค้า/มี SKU/ยังไม่มี/ติ๊กไม่ออก + รหัสที่ว่างถัดไป + ปุ่ม "ตั้งรหัส" (wizard — ไม่ต้องมีสิทธิ์แก้หมวด เพราะหมวดผูกบัญชี) ลบรหัส = หยุดออกให้สินค้าใหม่ SKU เดิมคงอยู่; สร้างหมวดใหม่ยังทำที่ Product Categories (ต้องตั้งบัญชี)
- **เตือนตั้งรหัส**: หมวดใหม่ (ล่างสุด) ที่ยังไม่มีรหัสและไม่ได้ติ๊ก "ไม่ออก SKU ทั้งหมวด" พอมีสินค้าเข้ามา → สร้าง Activity "ตั้งรหัสหมวด SKU" ให้ผู้ดูแลรหัสสินค้าทุกคน (ครั้งเดียวต่อหมวด) — ตั้งรหัสหรือติ๊กไม่ออก SKU แล้ว Activity ปิดเอง; ตัวกรอง "มีสินค้าแต่ยังไม่มีรหัส" ในหน้ารหัสหมวด SKU. ตอนติดตั้ง/อัปเกรด 1.3.0 หมวดล่างสุดที่ยังไม่มีรหัสถูกตั้ง "ไม่ออก SKU ทั้งหมวด" ให้ (กันเตือนท่วม)
- กลุ่ม **ผู้ดูแลรหัสสินค้า (SKU)**: แก้รหัสหมวด SKU, ปุ่มออกรหัสใหม่, ติ๊กพิมพ์ฉลากแล้ว, เมนู คลังสินค้า › การตั้งค่า › จัดกลุ่มสินค้า › ประวัติ SKU / ตัวนับ SKU
- รหัสแบรนด์แก้ได้โดยกลุ่ม "ผู้ดูแลค่าจัดกลุ่มสินค้า" (โมดูลเดิม)

## เจนครั้งแรก (deploy)
ตั้งรหัสหมวด/แบรนด์ด้วย context `az_sku_no_auto=True` (ไม่ออกทันที) แล้วเรียก `env['product.template']._az_sku_generate_all()` — เรียงลำดับในแต่ละ หมวด+แบรนด์ ตามรหัสเดิม (ดัมมี่ตามชื่อ) แบบเดียวกับไฟล์ร่างที่บัญชีตรวจ
