# Autozone Product Invoice Policy

สินค้าที่ติ๊ก **เก็บสต็อก (Track Inventory)** จะได้นโยบายวางบิล **ตามจำนวนที่ส่งมอบ (Delivered quantities)** อัตโนมัติ
ทั้งตอนสร้างสินค้าใหม่และตอนติ๊ก/เปลี่ยนประเภท

- ทำไม: Odoo ตั้ง "ตามจำนวนที่สั่ง" ให้สินค้าทุกตัว → เปิดบิลได้ก่อนส่งของ → บัญชีพักสต็อก 1410002 ค้าง (สำรวจ 1 ต.ค. 2026: สินค้าใหม่ 154 ตัวตั้งผิด)
- ไม่แตะ: บริการ / สินค้าที่ไม่เก็บสต็อก (ยังเป็นค่าตามเดิมของ Odoo)
- SO เก่าไม่เปลี่ยนย้อนหลัง (core ตั้งใจไม่ recompute เมื่อนโยบายสินค้าเปลี่ยน)
- สินค้าที่มีอยู่แล้วไม่ถูกแก้ตอนติดตั้ง — ใช้สคริปต์ `scripts/usage_audit/invoice_policy_fix.py`
