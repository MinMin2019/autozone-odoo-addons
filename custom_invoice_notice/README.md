# custom_invoice_notice — ใบแจ้งหนี้ (Invoice Notice)

**ใบแจ้งหนี้ (ไม่ใช่ใบกำกับภาษี)** สำหรับงานบริการ ใช้ส่งลูกค้าเพื่อเรียกเก็บเงินก่อนออกใบกำกับภาษี
ตามแบบที่บัญชีส่งมา (`other/Autozone-Invoice-Notice-WHT-Preview.html`) และโฟลว์ที่บัญชีเคาะ 15 ต.ค. 2026 (**แบบ B**)

## โฟลว์ (แบบ B)
1. ส่งงานแล้ว → เปิด **ใบสั่งขาย (SO)** ที่ Confirm แล้ว → ปุ่ม **พิมพ์ใบแจ้งหนี้** (ยังไม่ออก IV ยังไม่ลงบัญชี)
   - ครั้งแรกระบบใส่ "วันที่ใบแจ้งหนี้" = วันนี้ + วันครบกำหนด = วันที่ + เงื่อนไขชำระเงินของใบ (แก้ได้ที่แท็บ Other Info)
   - ยอดขึ้น **รายงานคาดรับเงินรายวัน** เมื่อกรอก **"วันนัดรับเงิน"** เองเท่านั้น (v1.2.0, บัญชีเคาะ 28 ต.ค. 2026)
     วันครบกำหนดที่ระบบคิดให้ใช้พิมพ์บนใบ ไม่ใช่วันคาดรับ
2. ลูกค้าจ่าย → กด **Create Invoice** จาก SO ออก IV ลงวันที่รับเงิน → พิมพ์ชุดใบกำกับ 5 ใบตามปกติ → Register Payment (RV)
   - พอมี IV ยอดใบแจ้งหนี้ในรายงานคาดรับเงินหายไป ใบ IV เข้าแทน โดย IV ได้ "วันนัดรับเงิน" ต่อจาก SO (`_prepare_invoice`)
3. ใบ IV เก่าที่ Confirm ไปแล้ว (ช่วงเปลี่ยนผ่าน) ยังพิมพ์ใบแจ้งหนี้ได้จากปุ่มบน IV

## กติกาบนใบ
| เรื่อง | ที่มา |
|---|---|
| รายการ/ยอด (SO) | เฉพาะส่วนที่ยังไม่ออก IV (`qty_to_invoice`) ภาษีคำนวณจาก tax ของบรรทัด |
| หัก ณ ที่จ่าย | **เฉพาะบรรทัดบริการ** (product type = service หรือไม่มีสินค้า) × อัตราของลูกค้า; ของไม่หัก |
| ลูกค้าหักไหม | การ์ดลูกค้า แท็บ Sales & Purchase → "ลูกค้าหักภาษี ณ ที่จ่าย" + อัตรา (ค่าเริ่มต้น นิติบุคคล = 3%, บุคคล = ไม่หัก) |
| ปิดเฉพาะใบ | แท็บ Other Info → "ไม่แสดงหัก ณ ที่จ่ายบนใบแจ้งหนี้" |
| บัญชีรับโอน | บัญชีที่ลูกค้ารายนี้โอนเข้าล่าสุด → ไม่เคยโอนใช้ **บัญชีหลักของบริษัท** (ฟอร์มบริษัท → ใบแจ้งหนี้) แก้ทับต่อใบได้ |
| ชื่อสาขาธนาคาร | ช่องใหม่บนบัญชีธนาคาร (`res.partner.bank.az_branch_name`) |
| เลขที่ใบแจ้งหนี้ | = เลข SO (ไม่มีเลขชุดแยก) |
| สินค้า | **พิมพ์ไม่ได้** ถ้า SO มีสินค้า (VAT ของเกิดตอนส่ง ต้องออก IV ทันที) มีทั้งของและบริการให้แยก SO |

แสดงผลอย่างเดียว **ไม่ลงบัญชี** ลูกหนี้/รายได้จะลงตอนออก IV (บัญชีรับทราบแล้ว 15 ต.ค. 2026)

## ติดตั้งครั้งแรก (post_init_hook)
- ติ๊กหัก ณ ที่จ่ายให้ลูกค้านิติบุคคลทุกราย
- บัญชีหลัก = SCB ออมทรัพย์ บางปลาสร้อย `582-2-18275-3` (RVB2 รับเงินลูกค้ามากสุด) + ใส่ชื่อสาขา
- เติมบัญชีรับโอนให้ใบขายค้างชำระทั้งหมด

- `models/sale_order.py` — ฟิลด์/ยอดใบแจ้งหนี้บน SO, ปุ่มพิมพ์ + ด่านกันสินค้า, `az_notice_pages` (fill-front 33/17)
