# Autozone Receipt Numbering

ออกเลขใบรับเงินลูกค้า (สมุดรหัส RV…) อัตโนมัติ แทนการพิมพ์เอง — กติกาเอามาจากข้อมูลจริงบน prod (ม.ค.–ก.ย. 2026):

| รับเงินของ | เลขใบรับเงิน | ตัวอย่าง |
|---|---|---|
| ใบขายสด VAT (สมุด RCV) 1 ใบ | **เลขเดียวกับใบขาย** | ใบขาย CT2610005 → ใบรับเงิน CT2610005 |
| ใบขายสด Non-VAT (สมุด RCN) 1 ใบ | **เลขเดียวกับใบขาย** | SR2610003 → SR2610003 |
| ใบแจ้งหนี้ (IV) / หลายใบ / รับเงินไม่ผูกเอกสาร | **RP + ปีเดือน + ลำดับ** ชุดเดียวต่อกันทุกบัญชีธนาคาร เริ่ม 001 ทุกเดือน | RP2610001, RP2610002 … |

- ใช้เลขใบขายไม่ได้ (คนละเดือนกับวันรับเงิน หรือเลขนี้มีอยู่แล้วในสมุดเดียวกัน) → ใช้ RP แทน
- ถ้าพนักงานพิมพ์เลขไว้เองก่อนกด Post ระบบไม่แตะ
- RP ใช้ advisory lock ต่อเดือน กันสองคนกดพร้อมกันได้เลขซ้ำ และนับต่อจากเลข RP ที่พิมพ์ไว้เดิม
- ต้องคู่กับการตั้ง `sequence_override_regex` ของสมุด (1 ต.ค. 2026) ไม่งั้นเดือนในเลขไม่ถูกตรวจ
