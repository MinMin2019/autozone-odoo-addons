# Autozone PO Sequence Guard (custom_po_sequence_guard)

## 18.0.1.1.0 (17 พ.ย. 2026): เลข PO รายเดือน
- ตัวนับเลข PO เริ่มใหม่ทุกเดือนให้เอง (prefix `PO%(range_year)s%(range_month)s` + ช่วงตัวนับ 1 ช่วงต่อ 1 เดือน)
  - เดือนที่เพิ่งเริ่มใช้ตัวนับ: เริ่มต่อจากเลขสูงสุดที่มีคนใช้ไปแล้วในเดือนนั้น
  - คีย์ย้อนหลัง: เปลี่ยน "กำหนดเวลาการสั่งซื้อ" (date_order) เป็นเดือนเก่าก่อนบันทึก จะได้เลขของเดือนนั้น
  - หลังจากนั้นตัวนับเดินต่อเอง ถ้าเจอเลขที่มีคนพิมพ์ใช้ไปแล้วจะข้าม (พิมพ์เลขผิดล่วงหน้า ตัวนับก็ไม่กระโดดตาม)
- พิมพ์เลข PO เองได้เฉพาะตอนเป็น RFQ / ส่ง RFQ แล้ว (ยืนยันแล้วล็อก ทั้งหน้าจอและฝั่ง server)
  - view ตั้ง priority 999 เพื่อทับการปลดล็อกช่องเลขที่ทำไว้ใน Odoo Studio
  - พิมพ์ `New` หรือลบเลขออก = ให้ระบบออกเลขให้
  - ทุกการเปลี่ยนเลขบันทึกลง chatter
- รูปแบบเลขต้องเป็น `PO` + ปี ค.ศ. + เดือน + ลำดับ 3 หลัก เช่น `PO202611123`
  ถ้าต้องใช้เลขแบบอื่น ให้ติ๊ก "เลข PO รูปแบบพิเศษ"
- ห้ามบันทึกเลขซ้ำ (ตัดช่องว่าง + แปลงเป็นตัวพิมพ์ใหญ่ก่อนเทียบ) และมี popup เตือนทันทีตอนพิมพ์
- trigger `az_sequence_dr_audit_trg` บันทึกการเปลี่ยนค่าตัวนับรายเดือนลง Sequence Audit

## 18.0.1.0.0 (25 ก.ย. 2026)
