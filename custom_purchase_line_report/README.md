# custom_purchase_line_report

เมนู **Purchase › Reporting › รายการสั่งซื้อรายเดือน**

เลือกเดือน/ปี (และสถานะ PO) แล้วกด
- **ดูบนจอ** – list บรรทัด PO ของเดือนนั้น พร้อมผลรวมท้ายคอลัมน์ (กรอง/จัดกลุ่ม/Export ต่อได้)
- **Export Excel** – ไฟล์ .xlsx 1 ชีท ทุกบรรทัด + แถวรวม (สูตร =SUM)

คอลัมน์: เลข PO · วันที่ · ผู้ขาย · รหัสสินค้า · สินค้า · จำนวนสั่ง · จำนวนรับแล้ว · หน่วย · ราคาต่อหน่วย · ยอดรวม (ก่อน VAT) · ยอดรวม (รวม VAT) · สถานะ PO

- เดือนอิงจาก **Order Date** ของ PO ตามเวลาไทย (timezone ของผู้ใช้)
- ไม่นับ PO ที่ยกเลิก และบรรทัดหัวข้อ/หมายเหตุ
- จำนวนเป็นหน่วยสั่งซื้อบน PO, ราคาเป็นสกุลเงินของ PO
