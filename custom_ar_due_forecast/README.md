# custom_ar_due_forecast — คาดรับเงินลูกหนี้รายวัน

รายงาน "สรุปยอดรายได้ที่คาดว่าจะได้รับ ตาม DEL กำหนดรับชำระเงิน" แบบเดียวกับไฟล์ Excel ของฝ่ายบัญชี
(ลูกค้า × วันที่ 1..31 ของเดือน)

**เมนู:** Accounting → Customers → คาดรับเงินลูกหนี้รายวัน
เปิดเป็นหน้ารายงานบนจอแบบ P&L (OWL client action `custom_ar_due_forecast.report`):
เลือกเดือนด้วย ◀ ▶ หรือช่องเดือน (ค่าเริ่มต้น = เดือนหน้า), คลิกตัวเลขเพื่อเปิดรายการใบแจ้งหนี้เบื้องหลัง,
ปุ่ม PDF / Excel ด้านบน · เดือนที่เลือกจำไว้เมื่อกด breadcrumb กลับ

## แหล่งข้อมูล
| ช่อง | มาจาก |
|---|---|
| วันที่ 1..31 | `amount_total_signed` ของใบแจ้งหนี้ขาย posted ที่ `invoice_date_due` ตรงวันนั้น (ใบลดหนี้ติดลบ) |
| ค้างยกมา | `amount_residual_signed` ของใบที่ครบกำหนดก่อนเดือนและยังไม่จ่ายครบ |
| จำนวนเงิน (รับแล้ว) | ยอดใบ − คงค้าง ของใบในเดือน |
| วันที่รับเงิน | วันที่ล่าสุดของรายการที่จับคู่กับใบ (account.partial.reconcile) |
| Due | เงื่อนไขชำระเงินของลูกค้า ถ้าไม่ตั้ง → ค่าที่พบบ่อยสุดของ (ครบกำหนด − วันที่ใบ) 12 เดือนล่าสุด |

- แถวลูกค้า = มีใบครบกำหนดในเดือน ∪ มีใบค้างยกมา ∪ มีใบเปิดครบกำหนดเดือนถัดไป ∪ ออกใบใน N เดือนล่าสุด (แถวว่าง)
- หมวด 1 เงินสด = แถว "ลูกค้าเงินสด" = ยอดรับจริงจากใบเสร็จ (`out_receipt` เช่น CT จากสมุด Cash Receipt VAT/Non-VAT) ลงช่องตาม `invoice_date` (วันรับเงิน) คลิกดูใบเสร็จได้ · เดือนที่ไม่มียอด (เช่น เดือนอนาคต): หน้าจอ/PDF ไม่แสดงหมวด, Excel เว้นแถวว่างให้กรอกเอง
- ไม่มีหมวดเงินยืม · หมวด 2 = ลูกหนี้การค้าจาก Odoo · แถว "รวมรายได้ทั้งสิ้น (1-2)"
- ชีทที่ 2 "รายละเอียดใบแจ้งหนี้" ใช้ตรวจสอบตัวเลขรายใบ
- หน้าจอ / PDF (A4 แนวนอน): แสดงเฉพาะลูกค้า วันที่ และคอลัมน์ที่มียอด ชื่อลูกค้าย่อ (ตัด บริษัท/จำกัด, สาขาที่ 00002 → สาขา 2) ไม่มีแถวเงินสด

## ข้อจำกัด
ศูนย์บริการที่ออกใบแจ้งหนี้ใน Odoo วันเดียวกับที่รับเงิน (ค่าแรง Subcontract) จะไม่มียอดคาดการณ์ล่วงหน้า
→ แถวว่างให้บัญชีกรอกเอง จนกว่าจะออกใบตอนส่งงานพร้อมวันครบกำหนด
